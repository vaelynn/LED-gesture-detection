# LED Gesture Detection System

## Overview
This project uses computer vision (OpenCV) to detect hand gestures and control multiple LEDs in real time via an Arduino UNO.

---

## Demo
[Watch Demo](assets/demo.mp4)

---

## How It Works
1. A webcam captures live video input  
2. OpenCV processes the image to detect hand gestures  
3. Detected gestures are interpreted as control signals  
4. Signals are sent to the Arduino UNO  
5. LEDs respond based on the detected gesture  

---

## Components Used
- Arduino UNO R3  
- Breadboard  
- LED lights (x5)  
- Webcam  

---

## Technologies
- OpenCV (for gesture detection)  
- Arduino (for LED control)
